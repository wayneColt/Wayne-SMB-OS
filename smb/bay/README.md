# smb/bay — diagnostic recall (the runner)
Pure, stateless, no model. `diagnosticRecall({query, rows, standard, limit, stop_words})` ranks the shop's own completed repair orders for a symptom and reports whether each vehicle came back; `comebackWatch({rows, window_days})` computes the comeback label and reports right-censoring instead of a rate. Every echoed note passes `scrub()` (VIN, phone, email). The public contract (schemas, rubric, packet, clock, pricing, golden cases) lives in the contracts repo; `make_golden.mjs <dir>` regenerates its fixture and golden set from this runner so no expected output is hand-written. Tests: `node --test`.
